# Королевские Шахматы — полноценный сайт

Готовый проект: онлайн-шахматы с матчмейкингом по ЭЛО, 16 ботами, Stockfish,
разбором партий, чатом и зрителями. Без внешних npm-зависимостей.

**Разбор партии** — полноценный анализатор:
- **График оценки** по ходам (клик — переход к нужному ходу);
- **Точность по стадиям**: дебют / миттельшпиль / эндгейм;
- **Переломные моменты** — 3 крупнейшие просадки с переходом к ходу;
- **Лучшая линия** от Stockfish в шахматной нотации «что стоило сыграть»;
- **Средняя потеря пешки** (ACP) и легенда по классам ходов;
- **Переход к следующей/предыдущей ошибке** кнопками в панели;
- **Дебютная теория** (как на chess.com): ходы из книги — «Дебют (теория)»
  с точностью 100%, а не «Неточность» (30+ вариантов в `openings.js`).

## Вариант 1: Render (бесплатно, быстрее всего)

1. Залейте **содержимое этой папки** в корень GitHub-репозитория.
2. Зайдите на https://render.com → **New → Web Service** → выберите репозиторий.
3. Параметры (подхватятся из `render.yaml`, но проверьте):
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Plan: **Free**
   - Health Check Path: `/health`
4. **Create Web Service**. Через 2–5 минут получите ссылку:
   `https://royal-chess-online.onrender.com`
5. Скиньте ссылку друзьям. Всё.

**Автодеплой:** в Render откройте Settings → Deploy Hook, скопируйте URL.
В GitHub: Settings → Secrets → Actions → New secret с именем `RENDER_DEPLOY_HOOK`.
Теперь каждый `git push` в `main` обновляет сайт.

> Бесплатный план засыпает после 15 мин простоя — первый вход может занять ~30 секунд.
> Это нормально. Проплаченный Starter — без засыпания.

## Вариант 2: Railway / Fly.io

Подойдёт любой хостинг с Node.js и WebSocket. Запуск везде один: `npm start`.
Порт берётся из переменной `PORT`, которую хостинг задаёт сам.

## Вариант 3: Docker (любой VPS / Cloud Run / Fly)

```bash
docker build -t royal-chess .
docker run -d -p 8080:8080 royal-chess
```

Откройте `http://localhost:8080`.

## Вариант 4: локально

`start.bat` (Windows) или `node server.js` → `http://localhost:10000`.

## Свой домен

На хостинге добавьте CNAME на выданный адрес. В Render: Settings → Custom Domains.
`Sitemap` и `robots.txt` создаются автоматически с вашим доменом — править ничего не нужно.

## Как играть

1. Откройте сайт в двух браузерах (или скиньте ссылку друзьям).
2. **Онлайн** → введите имя → «Сохранить».
3. **Подбор** → «С ЭЛО» (рейтинг меняется) или «Без ЭЛО» → «Начать».
4. Или «Создать комнату» → скиньте код → друг вводит его в «Войти по коду».
5. Есть чат, сдача, ничья, зрители и разбор партии после игры.

## Проверка

- `https://<домен>/health` → `{"ok":true,...}`
- `https://<домен>/sitemap.xml` → XML с вашим доменом
- `https://<домен>/netflix` → красивая 404

## Данные

- Рейтинги: `ratings.json` на сервере (на бесплатных планах сбрасываются при redeploy —
  это нормально; для постоянного хранилища подключите диск/БД).
- Имя, настройки, история партий — в браузере игрока.
